## 三、可直接照读的旁白稿

大家好，我们的作品是《基于 ESP32-P4 的边缘 AI 工业质检终端》。它面向小型零部件抽检和实验室质检场景，主要解决人工观察效率低、漏检率高，以及单一视觉检测难以覆盖内部或背面缺陷的问题。

系统由 ESP32-P4 主控板、摄像头、I2S 麦克风、敲击机构、LCD 交互界面和执行机构组成。设备上电后会自动完成摄像头、AI 模型、音频采集和界面初始化。当前界面可以看到实时视频窗口、视觉检测状态、声学分析波形、AI 的 NG/OK 概率，以及 PASS、FAIL 和良率统计。

下面演示第一个核心功能，视觉缺陷检测。我们先放入一个正常样品，并点击 VISION START。系统会将摄像头画面输入端侧 AI 模型，在 ESP32-P4 本地完成推理，并在屏幕上显示 OK 结果和概率信息。

接下来换成一个表面有划痕或异常的样品。可以看到，系统识别到异常后，右侧结果区更新 NG 概率，统计栏同步记录 FAIL，界面也给出对应的报警状态。

第二个核心功能是声学敲击检测。点击 AUDIO START 后，系统会采集约 1 秒的敲击音频，并提取声学特征进行异常判断。正常样品的敲击声会显示为 GOOD，异常样品或声纹差异明显的样品会显示为 BAD 或 ANOMALY。

本作品的技术亮点主要有三点。第一，视觉 AI 模型直接部署在 ESP32-P4 上，本地完成推理，不依赖网络。第二，系统结合视觉和声学两种模态，既能检测表面异常，也能辅助判断材质或内部状态变化。第三，系统提供完整的人机交互界面，实时显示视频、概率、声学波形、报警和良率统计。

从演示结果看，系统已经实现了从采集、推理、显示到反馈的端侧闭环，适用于小批量产线、实验室抽检和教学演示等场景。以上就是我们的作品演示，谢谢观看。

## 四、现场拍摄操作教学

### 1. 拍摄前摆放

1. 把设备放在桌面中央，屏幕朝向摄像手机。
2. 摄像头视野里只保留检测区域和样品，不要放多余杂物。
3. 准备至少 3 个样品：一个正常件、一个明显划痕件、一个用于声学异常对比的样品。
4. 麦克风固定在样品附近，敲击点和样品位置每次尽量一致。
5. 手机横屏固定，建议 1080p、30fps。
6. 如果屏幕反光，关掉顶灯或让手机稍微俯拍。

### 2. 正常件视觉镜头怎么拍

1. 先拍屏幕处于待机状态，右侧按钮能看到 `VISION START`。
2. 手把正常样品放到检测区域，停 1 秒。
3. 点击 `VISION START`。
4. 等屏幕出现 OK、绿色框、OK 概率或 PASS 统计变化。
5. 不要立刻停止录制，多留 2 秒，方便剪辑。

旁白关键词：

- “端侧 AI 推理”
- “正常件 OK”
- “PASS 统计更新”

### 3. 缺陷件视觉镜头怎么拍

1. 不要移动手机。
2. 取走正常件，换成划痕件或异常件。
3. 让缺陷面朝向摄像头，保持光照稳定。
4. 等屏幕结果变成 NG、红色框、NG 概率或 FAIL 统计变化。
5. 如果结果不明显，可以重新摆正样品或让缺陷区域更靠近镜头中央。

旁白关键词：

- “异常样品”
- “NG 概率上升”
- “FAIL 统计更新”

### 4. 声学检测镜头怎么拍

1. 把样品放在固定敲击位置。
2. 镜头同时拍到样品、麦克风和屏幕底部声学区。
3. 点击 `AUDIO START`。
4. 如果继电器敲击机构已接好，等待它自动敲击；如果没有接好，就在点击后立刻手动敲击一次。
5. 等待屏幕底部显示 `GOOD`、`BAD` 或 `ANOMALY`，并拍到声学波形颜色或文字变化。

注意：当前固件点击 `AUDIO START` 会启动约 1 秒录音，并发送一次敲击触发事件。如果敲击机构没有实际接线，必须手动敲击，否则声学结果可能不稳定。

旁白关键词：

- “1 秒敲击音频”
- “I2S 麦克风”
- “声学特征”
- “GOOD / ANOMALY”

### 5. 执行机构镜头怎么拍

1. 如果舵机已经接好，拍摄右侧按钮 `SERVO REV`。
2. 点击一次，拍到舵机短动作。
3. 再点击一次，拍到舵机反向或复位动作。
4. 如果自动剔除机构未接好，旁白只说“执行机构反馈”或“预留剔除动作”，不要说“系统自动剔除不良品”。

旁白关键词：

- “反馈闭环”
- “执行机构动作”
- “可扩展到产线剔除”

### 6. 急停镜头是否要拍

建议补拍，但不一定放进主视频。拍法：

1. 设备运行时点击 `EMERGENCY STOP`。
2. 拍到视觉和声学状态进入急停，照明关闭或界面锁定。
3. 这个镜头可以放在技术亮点或安全设计里，时长 3 秒即可。

## 五、拍摄清单

- 手机横屏，1080p、30fps。
- 使用三脚架或固定支架。
- 拍摄前清理桌面，移走学校、实验室、姓名相关信息。
- 准备正常样品、缺陷样品、声学异常对比样品。
- 准备稳定照明，避免样品反光过强。

## 十一、现场常见问题和补救

### 视觉一直 NO SAMPLE

- 把样品放到画面中央。
- 增加照明，减少反光。
- 等待 1-2 秒让检测刷新。
- 重新点击 `VISION STOP` 再点击 `VISION START`。

### 缺陷件没有判成 NG

- 换更明显的划痕件。
- 让缺陷面正对摄像头。
- 不要让样品边缘过曝。
- 拍摄时可以多试几次，剪辑只保留结果稳定的一次。

### 声学检测没有明显变化

- 点击 `AUDIO START` 后立即敲击。
- 敲击力度保持一致。
- 麦克风靠近样品，但不要碰到桌面。
- 使用差异更明显的异常样品做对比。

### 舵机或执行机构没动作

- 只拍界面报警和统计变化。
- 旁白改成“系统预留执行机构反馈接口”，不要说“自动剔除已经完成”。
- 可以用 `SERVO REV` 手动演示机构动作。

- 时长小于 3 分钟。
- 文件小于 300M。
- 封面不超过 2 秒。

- 声学敲击动作和结果变化清楚。
